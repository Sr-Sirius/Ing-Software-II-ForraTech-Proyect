Dataset and input variables

The dataset ena_2019_pastos_ml.csv contains 26 pasture varieties and their usage proportions according to type of use reported in ENA 2019. The four models receive the same input variables from the terrain:

Input variable Range Description How it is used
Available area area_ha 0.5 – 1M ha Hectares available to the producer for sowing. Transformed as log(1 + area_ha) to reduce magnitude bias.
Protein gain (%) ganancia_proteina_pct 0 – 100% Percentage of nutritional improvement sought in the animals. Defines the target distribution of usage proportions.
Terrain climate clima warm / cold Thermal climate of the terrain. Encoded as clima_num and used as post-prediction affinity factor.
Type of use feature vector grazing / cut / rotational Intended use of the pasture. Determines the proportion weights of each feature.

Composite score

Weighted score of 7 features on a 0 to 1 scale. Represents the general aptitude of the terrain.

Detailed analysis by model

⌘ K-Means Clustering

  • Identifies natural groups without labels.
  • Effective for exploration and segmenting similar terrains.
  • Limitation: depends on K and scale.

⌁ K-Nearest Neighbors (KNN)

  • Intuitive and easy to implement.
  • Performance depends on local density of data.
  • Sensitive to noise and irrelevant features.

Why K-Means clustering does not have accuracy, precision or recall?

K-Means is an unsupervised algorithm: it does not use true labels (ground truth) to learn. Therefore, metrics such as accuracy, precision and recall, which require known correct classes, cannot be computed. Instead, internal clustering metrics are used: Silhouette, Inertia and Affinity.
