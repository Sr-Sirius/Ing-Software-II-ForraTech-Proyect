01

Business Understanding

Objetivo de negocio

¿Qué problema resuelve?

Determinar si las condiciones de un terreno (pH, humedad, altitud, temperatura) son óptimas o no para el cultivo forrajero, y recomendar el cultivo más adecuado según afinidad.

Contexto & usuarios

Público objetivo

  • Productores agrícolas y ganaderos
  • Técnicos agronómicos de campo
  • Plataforma AgroData (decisiones de siembra)
Clasificación binaria Recomendación de cultivo
02

Data Understanding

Fuente de datos

Dataset sintético

Archivo forrajeo_1000.csv con 1000 registros de cultivos forrajeros y rangos de condiciones agroecológicas.

Variables de entrada

Features principales

  • ph_min / ph_max
  • humedad_min / humedad_max
  • altitud_min / altitud_max
  • temp_min / temp_max
Variable objetivo

Target binario

Variable optimal (0/1) derivada del puntaje compuesto. 1 = condiciones óptimas; 0 = no óptimas.

03

Data Engineering

Feature engineering

Construcción de variables derivadas

  • ph_mid = (ph_min + ph_max) / 2
  • humedad_mid, altitud_mid, temp_mid análogos

Transformación a punto medio para representar el centro de cada rango.

Puntaje compuesto & target

Fórmula de aptitud

composite = 0.30 × ph_mid/9 + 0.20 × hum_mid/100 + 0.30 × alt_mid/4000+ 0.20 × temp_mid/45 optimal = composite > mean(composite)
Preprocesamiento

Escalado & split

  • Feature: solo composite (1 variable)
  • Escalado: StandardScaler
  • Split: 75% train / 25% test (stratify=y)
Función de afinidad

compute_affinity()

Para rankear cultivos: pesos 0.30 pH, 0.20 humedad, 0.30 altitud, 0.20 temperatura. Verifica si el valor del usuario cae dentro del rango del cultivo.

Configuración del modelo

  • max_iter=1000 para convergencia segura
  • Umbral de decisión: 0.5

01

Business Understanding

Objetivo de negocio

¿Qué problema resuelve?

Clasificar terrenos como óptimos o no óptimos para forraje usando probabilidad bayesiana, incorporando 8 variables de rango simultáneamente para mayor precisión que la regresión logística.

Diferencial vs. regresión logística

Ventaja bayesiana

  • Modela la incertidumbre de forma explícita
  • Utiliza todas las variables de rango (8 features)
  • Actualización probabilística por el teorema de Bayes
Clasificación probabilística 8 features

04

Model Engineering

Algoritmo

Gaussian Naive Bayes

Aplica el Teorema de Bayes:

P(optimal|features) = P(features|optimal) × P(optimal) ───────────────────────────────── P(features) GaussianNB estima P(features|class) como una distribución gaussiana.
Feature importance bayesiana

Poder discriminativo

Se calcula mediante la ratio de varianza entre clases: diferencia de medias normalizada por la desviación estándar combinada. Se muestra en generateFeatureImportancePlot().

01

Business Understanding

Objetivo de negocio

Clasificación con datos reales DANE

Cuatro modelos que usan el censo agropecuario DANE ENA 2019 para recomendar variedades de pasto reales según área sembrada, ganancia proteica deseada y clima (frío/cálido).

Modelos incluidos

Suite de 4 algoritmos

Bayes DANE RF DANE KNN DANE K-Means DANE

Cada uno recomienda variedades con una perspectiva algorítmica distinta.

02

Data Understanding

Fuente de datos

DANE ENA 2019

Encuesta Nacional Agropecuaria 2019. Registros reales de variedades de pasto sembradas en Colombia con datos de uso, área y clima.

Variables disponibles

Columnas clave

  • variedad – nombre del pasto
  • area_sembrada_ha – área en hectáreas
  • clima – frío / cálido
  • prop_banco_proteina
  • prop_corte, prop_pastoreo_*
Naturaleza del problema

Multiclase real

A diferencia del dataset sintético, aquí el target es la variedad de pasto (problema multiclase). Se añade una capa binaria de aptitud proteica para métricas comparables.

03

Data Engineering

Features construidas

Pipeline compartido (todos los modelos DANE)

score_proteina = 0.50 × prop_banco_proteina + 0.30 × prop_corte + 0.10 × prop_pastoreo_rot + 0.10 × prop_pastoreo_cont log_area = log1p(area_sembrada_ha) clima_num = {"frio":1, "calido":0}
Vector de usuario

buildUserVector(area, proteína%, clima)

gp = ganancia_proteina / 100 prop_banco = min(gp×0.60, 0.60) prop_corte = min(gp×0.40, 0.40) prop_rot = max(1 - banco - corte - 0.05, 0) prop_cont = max(0.05, residual) → [log_area, score_p, clima_num, prop_cont, prop_rot, prop_corte, prop_banco]
Target binario (modelos supervisados)

Aptitud alta / baja

optimal = score_proteina ≥ median(score_proteina). Se usa la mediana (no la media) para robustez frente a outliers.

Codificación de clases

LabelEncoder (RF & Bayes DANE)

Las variedades se codifican numéricamente con LabelEncoder para entrenamiento multiclase. La decodificación se aplica en la predicción final.

04

Model Engineering

Bayesiano DANE

GaussianNB + ajuste por clima

Entrena un Naive Bayes multiclase sobre variedades. Las probabilidades posteriores se ajustan con un factor de likelihood por clima (×1.25 si coincide, ×0.75 si no) y se renormalizan.

Random Forest DANE

Modelo dual: multiclase + binario

  • Modelo 1: RF multiclase (200 árboles) → recomienda variedad
  • Modelo 2: RF binario balanceado → clasifica aptitud alta/baja
  • Umbral optimizado por F1 en entrenamiento
KNN DANE

Vecinos más cercanos (K=3)

  • NearestNeighbors(k=3, metric='euclidean') para recomendación
  • KNeighborsClassifier(weights='distance') para métricas
  • Ajuste de afinidad por clima: ×1.20 / ×0.80
  • PCA 2D para visualización de vecindad
K-Means DANE

Clustering no supervisado (K=4)

  • KMeans(n_clusters=4, n_init=10)
  • Métricas aproximadas: target binario por proporción de óptimos en cluster
  • PCA 2D para visualización de clusters
  • Afinidad: inverso de la distancia euclidiana al centroide
05

Model Evaluation

Modelos supervisados (Bayes, RF, KNN)

Métricas estándar

Exactitud Precisión Recall F1 ROC AUC

Validación cruzada estratificada con StratifiedKFold. El número de folds se adapta al mínimo de muestras por clase.

K-Means (no supervisado)

Métricas aproximadas

Al no tener etiquetas, se construye un target proxy basado en score_proteina ≥ mean. Las métricas de exactitud, F1 y AUC se interpretan como indicadores de cohesión del cluster, no como métricas de clasificación.

06

Prediction System

Entradas del usuario

Parámetros de predicción

  • area_ha – hectáreas del terreno
  • ganancia_proteina_pct – objetivo proteico (0–100%)
  • clima – "frio" o "calido"
Carga lazy (load_model)

Patrón de inicialización

Todos los modelos DANE implementan un patrón de lazy loading: se entrenan solo una vez al primer uso mediante load_model_B(), load_model_RF(), load_model_K(), load_model_KM(). Las variables globales garantizan que no se reentrenen en llamadas sucesivas.

Flujo Bayes & RF DANE

Inferencia multiclase

1. buildUserVector() → 7 features 2. scaler.transform() 3. model.predict_proba() → probs por variedad 4. Ajuste por factor de clima 5. Re-normalización bayesiana 6. top_n variedades rankeadas
Flujo KNN & K-Means DANE

Inferencia por similitud

1. buildUserVector() → 7 features 2. scaler.transform() 3. knn.kneighbors() o kmeans.predict() 4. Filtro + ajuste de afinidad por clima 5. Ordenar por afinidad = 1/(1+dist) 6. Retornar variedad + ranking top-K
