Data Understanding

▤

Data Source

Synthetic dataset with 1,000 forage crop records and agroecological condition ranges.

1,000 records
▧

Input Variables

  • ph_min / ph_max
  • humedad_min / humedad_max
  • altitud_min / altitud_max
  • temp_min / temp_max
☑

Target Variable

optimal is a binary variable derived from the composite score.

0 = Not optimal 1 = Optimal
03

Data Engineering

01 Midpoints

Build average values from min/max ranges.

02 Composite

Weighted forage suitability score.

03 Scaling

StandardScaler normalization.

04 Dataset Split

75% train / 25% test stratified.

ƒ

Composite Formula

composite =
  0.30 × ph_mid / 9 +
  0.20 × hum_mid / 100 +
  0.30 × alt_mid / 4000 +
  0.20 × temp_mid / 45
⚙️

Affinity Function

Ranks forage crops by checking whether user terrain values fall inside each crop's valid agroecological range.

04

Model Engineering

🧠

Logistic Regression Algorithm

Linear generalized model that applies the sigmoid function over the scaled composite score to estimate the probability of optimal terrain.

LogisticRegression max_iter=1000 threshold=0.5
▣

Model Formula

P(optimal | x) =
  1 / (1 + e^(-z))

z = β0 + β1 · composite

Data Engineering

04

Model Engineering

Bayes + Random Forest

  • GaussianNB multiclase with climate likelihood adjustment.
  • Random Forest with multiclass and binary branches.
  • Threshold optimized for F1.

KNN + K-Means

  • KNN by nearest neighbors and climate-adjusted affinity.
  • K-Means with 4 clusters and PCA visualization.
  • Affinity based on distance to centroid or neighbors.
