Visión general

AgroML es un sistema web de recomendación de cultivos forrajeros construido con Flask y scikit-learn. Implementa dos módulos independientes: uno sobre un dataset sintético de 1 000 registros y otro sobre datos reales del ENA 2019 (DANE).

Objetivo: dado un conjunto de condiciones del terreno (pH, humedad, altitud, temperatura) o del productor (área disponible, ganancia de proteína deseada, clima), el sistema recomienda la variedad forrajera más adecuada.

La arquitectura sigue un diseño de 4 capas desacopladas que separa el modelo ML de la interfaz web, facilitando el mantenimiento y la extensión.

Arquitectura de capas Flask

El sistema sigue un diseño de 4 capas desacopladas. Cada capa conoce solo a la capa inmediatamente inferior.

Capa 4 – Routes · recibe HTTP, devuelve HTML/JSON app/routes/recommendation_routes.py
↓ llama al servicio
Capa 3 – Service · reglas de negocio, gráficas app/services/recommendation_service.py
↓ invoca predict()
Capa 2 – Pipeline · validación, preprocesamiento app/ml/pipelines/dane_pipeline.py
↓ delega al modelo
Capa 1 – Models · sklearn, entrenamiento, predicción app/ml/models/dane/ · app/ml/models/sintetyc_dataset/

Pipeline ML

El DanePipeline se instancia una sola vez al arrancar la app (create_app()) y entrena los 4 modelos en memoria. Las rutas nunca llaman directamente a los modelos.

Singleton pattern: cada modelo usa un guard if _model is not None: return para evitar re-entrenar en cada request.

Flujo de una predicción

# 1. Route recibe POST
data = request.form.to_dict()

# 2. Service extrae y valida
area_ha = float(data.get("area_ha", 50))

# 3. Pipeline construye el vector
user_vector = pipeline.build_user_vector(area_ha, proteina, clima)

# 4. Modelo predice
raw = model.predict(user_vector, clima)

# 5. Service devuelve dict al template
return { "result": raw["best_variety"], "plot": chart_b64, ... }

Modelos ML implementados

Dataset sintético (forrajeo_1000)

Regresión Logística Curva sigmoide sobre un score compuesto de las 4 variables del terreno. Predice si el terreno es óptimo (1) o no (0) y genera un ranking de afinidad por especie.

Dataset DANE (ENA 2019)

K-Means Agrupa las 26 variedades en 4 clusters. Asigna el terreno del usuario al cluster más cercano y recomienda la variedad más próxima al centroide.

KNN (K=5) Encuentra los 5 vecinos más cercanos al vector del usuario en espacio euclidiano escalado. Ajusta la afinidad por clima.

Random Forest 200 árboles de decisión votan por la variedad. Incluye importancia de variables y cross-validation de 3 folds.

Naive Bayes Calcula P(variedad|terreno) usando distribuciones gaussianas por clase. Aplica el teorema de Bayes con ajuste de prior por clima.

Configuración

Todas las rutas a datos y parámetros de modelos se centralizan en config.py.

class Config:
    DATA_PATH_FORRAJEO = os.path.join(BASE_DIR, "data", "forrajeo_1000.csv")
    DATA_PATH_PASTOS   = os.path.join(BASE_DIR, "data", "ena_2019_pastos_ml.csv")

    KMEANS_K         = 4
    KNN_K            = 5
    RF_N_ESTIMATORS  = 200
    RF_RANDOM_STATE  = 42

    PROTEIN_WEIGHTS  = {
        "banco_proteina"      : 0.50,
        "corte"               : 0.30,
        "pastoreo_rotacional" : 0.10,
        "pastoreo_continuo"  : 0.10,
    }
