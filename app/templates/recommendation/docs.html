1.

Datasets

The system uses two main datasets to train and evaluate machine learning models.

Synthetic Forage Dataset (forrajeo_1000.csv)

1,000 records

Generated with 52 forage species with random variation. Includes ranges of environmental and agronomic conditions.

Column Type Description
id int Unique identifier (1–1000)
nombre str Forage species name
ph_min / ph_max float pH range
humedad_min / humedad_max float Relative humidity range (%)
altitud_min / altitud_max float Altitude range (msnm)
temp_min / temp_max float Temperature range (°C)

ENA 2019 Pasture Dataset (ena_2019_pastos_ml.csv)

26 varieties

Derived from the ENA 2019 pastures annex. Contains 26 pasture varieties with seeded areas and production properties.

Column Type Description
variedad str Pasture variety name
clima str Warm / Cold
area_sembrada_ha float Total seeded area
prop_pastoreo_continuo float Continuous grazing proportion
prop_pastoreo_rotacional float Rotational grazing proportion
prop_corte float Cut usage proportion
prop_banco_proteina float Protein bank proportion
score_proteina float Protein aptitude score
log_area float log1p(area_seeded_ha)
clima_num int 0 = warm, 1 = cold

4.

Pipelines (CRISP-ML)

Each machine learning model follows the CRISP-ML methodology with 6 phases.

01

Business Understanding

Define objectives, context and success criteria.

02

Data Understanding

Explore and analyze the data.

03

Data Engineering

Clean, transform and prepare features.

04

Model Engineering

Train models and tune hyperparameters.

05

Model Evaluation

Evaluate performance and compare models.

06

Prediction System

Deploy the model and generate predictions.

5.

ML Models

Synthetic

Logistic Regression

Sigmoid curve over a composite score from terrain variables. Predicts whether a terrain is optimal or not.

Synthetic

Naive Bayes

Gaussian probabilistic classifier using range variables and Bayesian likelihood.

Synthetic

Random Forest

Ensemble of decision trees with feature importance and robust terrain classification.

DANE

K-Means

Groups pasture varieties into clusters and recommends according to closest centroid.

DANE

KNN

Finds the closest real varieties to the user's production profile.

DANE

Bayes + RF DANE

Supervised real-data models that predict variety and evaluate protein suitability.
